# StayFinder

An accommodation booking platform built with
Next.js, React, TypeScript, Hono and Supabase.

## Features

- Browse accommodations
- Search and filter properties
- User registration and authentication
- Create and manage bookings
- Create and manage property listings
- Secure user ownership and authorization

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Hono
- TypeScript
- Zod

### Database
- Supabase
- PostgreSQL
- Supabase Auth
- Row Level Security

## Project Structure

- frontend: Next.js application
- backend: Hono REST API
- backend/supabase: database migrations
